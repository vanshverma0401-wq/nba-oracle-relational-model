# Data and usage

## Public data

All team, player, coach, city, venue, date, score, and box-score records in
`sample_data.sql` are original fictional demonstration data created for this
portfolio package. They do not reproduce a real roster, schedule, or game log.

The fictional rows are intended only to make joins, constraints, and query
structure reviewable. They cannot support claims about real players, teams, or
league performance.

## Historical code

`coursework/final_schema.sql` is the author's original generated database DDL.
It contains table and program definitions, not the original sports records.
It is kept separate from the redesigned fictional-data demonstration.

## Excluded private inputs

The public package excludes the original source-derived sample records, private
reports, screenshots, personal survey records, and instructional materials. A
reader does not need any of those inputs to inspect the reconstructed model.

## Reuse

The SQL and fictional sample data are provided under the repository license.
No rights to third-party league names, player records, logos, imagery, or data
sources are conveyed because those materials are not included.
